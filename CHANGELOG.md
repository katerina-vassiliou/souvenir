# Changelog

## Unreleased

- Souvenir now checks images before saving them to your collection, and says so when a capture is too large to keep instead of failing quietly.

## 1.2.0

- See what changed in each version from the Help screen, under What’s new.
- A clearer store listing: the extension is now called “Souvenir — Capture Web Elements as PNG”, with an updated description.

## 1.1.1

- Click the Souvenir logo in the side panel to start collecting an element, the same as the keyboard shortcut. If Souvenir can’t start on the current tab yet, the panel says what to do.
- The packaged zip no longer includes macOS .DS_Store files.

## 1.1.0

First release.

- Collect any container as a PNG on the clipboard, from the right-click menu or a shortcut.
- Highlight a container like in dev tools and move to its parent or child with the arrow keys.
- Two ways to capture: a fast render from the page, and a stitched screenshot as a fallback. Smart mode chooses.
- Tall elements, sticky headers, bottom bars, scrolling panels and content that loads on scroll.
- A collection in the side panel with names, search, details, drag out and download.
- A colour palette of up to eight distinct colours for every souvenir, with one click to copy it as JSON from the collection or the details view, and click a swatch to copy its hex.
- Settings for capture method, background, padding and keeping every souvenir.
- Light and dark themes.
